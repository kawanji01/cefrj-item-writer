## 独立検査の指摘

## R22-01 — major — `tests/unit/test_fixtures.py:1200` / `tests/unit/test_fixtures.py:1279` / `tests/unit/test_fixtures.py:1409` / `tests/unit/test_fixtures.py:2414`

1. **指摘内容**: CI-R-03のsensitive callableコンテナ追跡は、名前に束縛済みのコンテナを反復する形、dict viewの`items()`から値を取り出す形、関数内のローカル変数を介してコンテナを返す形で引き続きfail-openになる。実際に、次の3反例はいずれも`contract_dict_violations()`が違反ゼロを返したが、実行時には`unknown_helper()`由来の値を`write_json`へ渡す。

   ```python
   from tests.support import write_json
   calls = [write_json]
   for fn in calls:
       fn(candidate_path, unknown_helper())
   ```

   ```python
   from tests.support import write_json
   calls = {"sink": write_json}
   (key, fn), = calls.items()
   fn(candidate_path, unknown_helper())
   ```

   ```python
   from tests.support import write_json
   def choose():
       calls = (write_json,)
       return calls
   choose()[0](candidate_path, unknown_helper())
   ```

   `static_callable_container()`が追跡済み名前を認識しても、`sensitive_terminal_in()`はその名前のコンテナ要素を参照しないため、`for`のiterator taintへ到達しない。`unresolved_binding_terminal()`は`items`を未知抽出のfail-closed対象から明示的に除外する一方、`target_bindings()`は`values()`しか要素対応を復元しない。さらに`returned_callable_container()`は関数本体のローカル代入を先に解析せず、`return calls`を外側scopeの`containers`だけで評価する。これらにより、第4節fixtureでも製品直前段出力でもない入力をJSON書込みsinkへ到達させる将来のテストを、マージゲートが検出できない。

2. **根拠となる設計文書の規則ID**: `docs/testing-and-acceptance.md` CI-R-03・TST-08、`IMPLEMENTATION_PLAN.md` M8 DoD 1。

3. **具体的な修正案**: sensitive callableを含むコンテナのidentityを、名前の反復、`keys()` / `values()` / `items()`の各view、アンパック、ネストした抽出呼出しへ伝播する。ローカル関数の戻り値は、関数scope内の代入とコンテナ状態を解析してから評価する。要素対応を静的に確定できない反復・抽出は、sensitiveコンテナを消費する時点で`unresolved-sensitive`としてfail-closedにする。上記3形と`next(iter(calls.values()))`を自己負回帰へ追加し、同形で正準fixture由来の値だけを渡す正常例も固定する。

## R22-02 — major — `.claude/settings.json:5` / `.claude/settings.json:64` / `.claude/settings.json:100`

3. **具体的な修正案**: `.claude/settings.json`のdeny規則、または`Read`にも適用する専用PreToolUseガードで、相対・絶対の`output/<set_id>/.staging/flow-state.json`だけを拒否する。C12のBash子プロセスによる内部読取りと、ホストの`flow_control.py status`は維持する。Readイベントの相対パス・絶対パスが拒否され、通常の仕様・監査ファイル読取りは許可されることをCLI回帰へ追加する。
